Pipeline intelligence dashboard

A single source of truth for project prospecting, so the BizDev team works from one clean list instead of several provider files.

What
Consolidates 500+ project pipelines from 3 data providers into four sheets: Projects, Supplied, Archived and Pipeline.
How
Apps Script moves records by column name, never by position, and shows a validation form before anything is moved or copied.

Concrete pump monitoring app

A mobile web app that replaced reporting over WhatsApp for a concrete pump rental operation.

What
Two parts: Job (schedule, stages, planned against realised volume) and Maintenance (service, purchases, fuel and oil).
How
Each job moves through Planning, Departed, Arrived, Done and Back at pool, with camera photos stamped with GPS. Installs on the phone's home screen.
Care
Built with the field team's feedback: everyone can enter and view, and each change shows who made it.
  • Progressive web app
  • Google Sheets
  • Apps Script
  • Netlify
  • Built with Claude
